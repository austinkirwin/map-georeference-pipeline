# Reviewed map manifests

Save one reviewed manifest per map in this directory after landmark selection and human review.

A manifest should preserve:

- the map identifier and source citation;
- the raw-source checksum or storage URL;
- control-point pixel and geographic coordinates;
- each point's role, confidence, and reviewer notes;
- transform method, CRS, residuals, and independent-check results;
- issue number and review decision.

Do not store generated TIFFs, COGs, tiles, or other large derivatives here.
